**Шаблонный `ref` (template ref)** — это специальный атрибут во Vue, который позволяет получить прямую ссылку на конкретный DOM-элемент или экземпляр дочернего компонента после его отрисовки (рендера). 
В React полным аналогом для DOM-элементов является хук `useRef`.

### Как это работает (до Vue 3.5)
Во Vue 3 с использованием `<script setup>` процесс связи состоит из двух шагов:
1. В секции `<script setup>` создается реактивная переменная с помощью `ref()` со значением по умолчанию `null`. **Важно:** имя этой переменной должно точно совпадать со значением атрибута `ref` в шаблоне.
2. В секции `<template>` добавляется атрибут `ref="имяПеременной"` к нужному HTML-тегу или компоненту.

Vue автоматически "найдет" переменную с таким же именем и привяжет к ней элемент.

### Нюансы реализации
*   **Доступность только после монтирования (`onMounted`):** На момент инициализации компонента (в корне `<script setup>`) DOM еще не существует. Поэтому значение `ref` будет `null`. Обращаться к элементу можно только внутри хука `onMounted` или в обработчиках событий (например, по клику), когда DOM уже точно отрисован.
*   **Распаковка через `.value`:** Поскольку мы используем стандартный реактивный `ref` из Vue, чтобы получить сам DOM-узел, в скрипте всегда нужно писать `.value` (например, `myInput.value.focus()`).
*   **DOM-элемент vs Компонент:** 
    *   Если повесить `ref` на обычный HTML-тег (`<div ref="myDiv">`), в `.value` попадет нативный **DOM-узел** (например, `HTMLDivElement`), и вы можете вызывать на нем стандартные JS-методы (фокус, скролл, получение размеров).
    *   Если повесить `ref` на Vue-компонент (`<MyButton ref="myBtn">`), в `.value` попадет **экземпляр этого компонента**. 
*   **Работа с `v-for`:** Если использовать `ref` внутри цикла `v-for`, то Vue автоматически соберет все элементы в массив. То есть `ref.value` будет массивом DOM-элементов или компонентов. Порядок элементов в этом массиве не гарантируется!

### Примеры для понимания и запоминания

#### Пример 1: Доступ к нативному DOM-элементу (Автофокус)
Самый классический пример использования — установить фокус на поле ввода при загрузке страницы.

```vue
<script setup>
import { ref, onMounted } from 'vue'

// 1. Создаем ref. Имя "inputRef" совпадает с атрибутом в шаблоне.
const inputRef = ref(null)

onMounted(() => {
  // 2. DOM уже отрисован, можем взаимодействовать
  // Обязательно используем .value!
  inputRef.value.focus()
})
</script>

<template>
  <div>
    <!-- Привязываем созданный ref к элементу -->
    <input ref="inputRef" placeholder="Сюда будет фокус" />
  </div>
</template>
```

#### Пример 2: Использование ref с `v-for` (Массив элементов)
```vue
<script setup>
import { ref, onMounted } from 'vue'

const list = ['Яблоко', 'Банан', 'Апельсин']
// ВАЖНО: инициализируем пустой массив, а не null!
const itemsRefs = ref([])

onMounted(() => {
  // itemsRefs.value содержит массив DOM-элементов <li>
  itemsRefs.value.forEach(li => {
    console.log('Текст элемента:', li.textContent)
  })
})
</script>

<template>
  <ul>
    <!-- Один и тот же ref для всех элементов в цикле -->
    <li v-for="item in list" :key="item" ref="itemsRefs">
      {{ item }}
    </li>
  </ul>
</template>
```

#### Пример 3: [Доступ к дочернему компоненту](Доступ%20к%20дочернему%20компоненту.md)
Мы можем повесить `ref` на другой компонент и вызвать его метод.

**ChildComponent.vue**
```vue
<script setup>
// Тут какой-то код компонента-ребенка
</script>

<template>
  <div>Я ребенок!</div>
</template>
```

**ParentComponent.vue**
```vue
<script setup>
import { ref } from 'vue'
import ChildComponent from './ChildComponent.vue'

const childRef = ref(null)

const doSomethingWithChild = () => {
  // Здесь мы обращаемся к экземпляру дочернего компонента.
  console.log(childRef.value)
}
</script>

<template>
  <div>
    <!-- Вешаем ref на компонент -->
    <ChildComponent ref="childRef" />
    <button @click="doSomethingWithChild">Проверить ребенка</button>
  </div>
</template>
```

*Интересный факт для собеседования:* В Vue 2 (или без `<script setup>`) через `ref` дочернего компонента родитель получал доступ ко **всем** его данным и методам. Но в современном Vue 3 с `<script setup>` дочерние компоненты **"закрыты" по умолчанию** для родителя в целях инкапсуляции. И если в Примере 3 мы попробуем вызвать какой-то метод дочернего компонента, у нас ничего не выйдет.
