### Концепция и Теория

**Какую задачу это решает?**
Координация асинхронных операций в дереве компонентов. `Suspense` позволяет «поставить рендеринг на паузу», пока дочерние компоненты загружают данные (или пока загружается сам код компонента), и показать вместо них fallback-состояние (например, спиннер или скелетон).

**Как работает «под капотом»:**
Когда компонент Vue использует top-level `await` внутри `<script setup>` (или имеет асинхронную функцию `setup()`), он становится **асинхронной зависимостью**.
- Встретив такой компонент, Vue понимает: «Я не могу его отрендерить прямо сейчас, мне нужно подождать выполнения промиса».
- Если этот компонент обернут в `<Suspense>`, Vue приостанавливает рендер дерева в этом месте.
- Вместо самого компонента рендерится то, что передано в слот `#fallback`.
- Как только все промисы (всех вложенных асинхронных компонентов) разрешаются (resolve), Vue убирает fallback и рендерит основное дерево (слот `#default`).

### Синтаксис и База

`Suspense` — это встроенный компонент (как и `Teleport`), его не нужно импортировать.
Он ожидает два именованных слота: `#default` и `#fallback`.

**Родитель (оркестратор):**
```html
<Suspense>
  <!-- Основной контент, который может содержать асинхронные компоненты -->
  <template #default>
    <AsyncProfileComponent />
  </template>

  <!-- Что показываем, пока загружается #default -->
  <template #fallback>
    <LoadingSpinner />
  </template>
</Suspense>
```

**Дочерний компонент (AsyncProfileComponent.vue):**
Главная магия Vue 3: вы просто используете `await` на верхнем уровне в `<script setup>`.
```javascript
<script setup>
// Запрос выполнится до того, как компонент будет отрендерен
const response = await fetch('/api/profile')
const userData = await response.json()
</script>
```

### Сравнение с React (Аналогии и Отличия)

- **React `<Suspense>` = Vue `<Suspense>`** (по сути одно и то же).

- **Триггер для Suspense:**
	- **В React:** Чтобы «приостановить» Suspense, компонент должен выбросить Promise (throw Promise) наружу. Обычно это делается через специальные библиотеки (Relay, SWR, React Query) или через экспериментальные фичи (React Server Components, хук `use`).
	- **Во Vue:** Триггером является простой **top-level `await`** внутри `<script setup>`. Это делает код гораздо чище и понятнее для разработчика. Вы просто ждете данные, а Vue сам перехватывает этот промис.

- **Lazy Loading компонентов:**
	- И в React (`React.lazy()`), и во Vue (`defineAsyncComponent()`) Suspense перехватывает ленивую загрузку самого JS-файла компонента.

- **Статус API (Важно):**
	- В React Suspense является стабильной частью архитектуры уже давно.
	- Во Vue `<Suspense>` до сих пор официально имеет статус **Experimental** (экспериментальная фича). Его API может немного измениться в будущем, хотя он уже широко используется на практике (особенно с Nuxt 3, где он встроен под капот).

### Важные нюансы (Где можно выстрелить в ногу)

1. **Top-level await требует Suspense:**
   Если вы напишете `await fetch(...)` в `<script setup>`, но забудете обернуть этот компонент в `<Suspense>` где-то выше по дереву (в родителе), **компонент вообще не отрендерится**, и вы увидите пустое место (и предупреждение в консоли).

2. **Suspense ловит ВСЁ дерево:**
   Если внутри `#default` у вас несколько асинхронных компонентов, Suspense дождется загрузки **всех**, и только потом покажет контент. Если вы хотите, чтобы они загружались независимо (показывая отдельные спиннеры), вам нужно обернуть каждый компонент в свой собственный `<Suspense>`.

3. **Обработка ошибок:**
   Suspense **не ловит ошибки**! Если ваш `await fetch` упадет, Suspense не сможет это обработать. Для перехвата ошибок нужно использовать хук `onErrorCaptured` в родительском компоненте (аналог ErrorBoundary в React).

### Пример для заметок

Создадим панель управления, которая ждет загрузки профиля пользователя и списка его задач.

**Dashboard.vue (Родитель)**
```vue
<template>
  <div class="dashboard">
    <h1>Панель управления</h1>

    <Suspense>
      <!-- Этот слот появится только когда загрузятся ОБА дочерних компонента -->
      <template #default>
        <div class="content">
          <UserProfile />
          <UserTasks />
        </div>
      </template>

      <!-- Этот слот виден во время загрузки -->
      <template #fallback>
        <div class="loading-state">
          <p>Загрузка данных пользователя...</p>
        </div>
      </template>
    </Suspense>
  </div>
</template>

<script setup>
// Импортируем компоненты как обычно
import UserProfile from './UserProfile.vue'
import UserTasks from './UserTasks.vue'
</script>
```

**UserProfile.vue (Асинхронный ребенок)**
```vue
<template>
  <div class="profile">
    <img :src="user.avatar" />
    <h2>{{ user.name }}</h2>
  </div>
</template>

<script setup>
// Top-level await! Vue сам поймет, что нужно приостановить Suspense.
const res = await fetch('https://api.example.com/user/1')
const user = await res.json()

// Компонент не отрендерится, пока этот код не выполнится до конца.
</script>
```

**Резюме для React-разработчика:**
`<Suspense>` во Vue работает почти так же, как в React, но его использование с данными намного проще благодаря встроенной поддержке `await` на верхнем уровне в `<script setup>`. Не нужно кидаться промисами (throw Promise) — просто пишите синхронно выглядящий асинхронный код. Но помните, что фича всё ещё считается экспериментальной!
