### Концепция и Теория

**Какую задачу это решает?**
Рендеринг разных компонентов в одном и том же месте шаблона в зависимости от состояния (переменной). 
Типичные примеры:
- Переключение вкладок (Tabs), где каждая вкладка — это отдельный компонент.
- Динамический рендеринг блоков, пришедших с бэкенда (например, CMS отдает массив: `[{type: 'text'}, {type: 'image'}, {type: 'video'}]`).
- Шаги мастера (Wizard/Stepper) или многостраничные формы.

**Как работает «под капотом»:**
Vue предоставляет специальный зарезервированный тег `<component>`. Он ничего не рендерит сам по себе. Он ждет обязательный атрибут `:is`.
- Если в `:is` передать строку с именем HTML-тега (например, `'div'` или `'h1'`), Vue отрендерит этот тег.
- Если в `:is` передать сам объект компонента Vue, Vue инстанцирует (создаст) и отрендерит этот компонент.
- При изменении значения `:is` Vue **уничтожает** старый компонент (срабатывает `onUnmounted`) и **создает** новый (срабатывает `onMounted`).

### Синтаксис и База

```vue
<!-- В шаблоне используем спец-тег component -->
<component :is="currentComponent" />
```

В `<script setup>` (Composition API) мы передаем не строковое имя компонента (как это было в старом Vue 2), а **сам импортированный компонент**:

```javascript
import { shallowRef } from 'vue'
import TabHome from './TabHome.vue'
import TabProfile from './TabProfile.vue'

// Храним сам компонент в переменной.
// Используем shallowRef, а не ref (важный нюанс, объясню ниже!)
const currentComponent = shallowRef(TabHome)

const goToProfile = () => {
  currentComponent.value = TabProfile
}
```
### Сравнение с React (Аналогии и Отличия)

- **Как мы делаем в React:**
  В React мы обычно используем переменные с заглавной буквы, в которые кладем функцию-компонент, либо пишем объектный маппинг:
  ```javascript
  // React-подход:
  const componentsMap = {
    home: TabHome,
    profile: TabProfile
  };
  const CurrentTab = componentsMap[activeTabKey];
  
  return <CurrentTab {...props} />
  ```
  -  **Как мы делаем во Vue:**
  Во Vue мы делаем почти то же самое (сохраняем компонент в переменную), но для рендеринга мы не можем написать `<currentComponent />` (шаблонизатор Vue так не работает). Вместо этого мы используем встроенный делегат: `<component :is="currentComponent" />`.

- **Передача пропсов:**
  И там, и там вы можете передавать пропсы динамически. 
  В React: `<CurrentTab {...commonProps} />`. 
  Во Vue: `<component :is="currentComponent" v-bind="commonProps" />` (одинаковые пропсы полетят в любой отрендеренный компонент).

### Важные нюансы (Где можно выстрелить в ногу)

1. **Используйте `shallowRef` вместо `ref`!**
   Это критически важный момент оптимизации. Если вы положите объект компонента (а импортированный `.vue` файл — это большой объект) в обычный `ref`, Vue попытается сделать весь этот объект глубоко реактивным. Это съест много памяти и выбросит предупреждение в консоль: *"Vue received a Component which was made a reactive object"*. 
   Поэтому всегда храните компоненты в `shallowRef` — нам нужно отслеживать только перезапись самой переменной, а не свойства внутри компонента.

2. **Потеря состояния при переключении (KeepAlive):**
   По умолчанию, когда вы переключаете `:is` с `TabA` на `TabB`, `TabA` полностью уничтожается. Если там была заполненная форма, данные исчезнут.
   Чтобы сохранить состояние скрытого компонента в памяти, оберните динамический компонент во встроенный тег `<KeepAlive>`:
   ```html
   <KeepAlive>
     <component :is="currentComponent" />
   </KeepAlive>
   ```

### Пример для заметок

Давайте сделаем классическую систему табов.

**App.vue**
```vue
<template>
  <div class="tabs-container">
    <!-- Навигация (переключаем значение переменной currentTab) -->
    <nav class="tabs-nav">
      <button 
        v-for="(tab, key) in tabsMap" 
        :key="key"
        :class="{ active: currentTab === tab }"
        @click="currentTab = tab"
      >
        {{ key }}
      </button>
    </nav>

    <!-- 
      Динамический рендеринг:
      Здесь появится тот компонент, который сейчас лежит в currentTab.
      Также мы можем передать ему пропсы (например, :user="user").
    -->
    <div class="tab-content">
      <KeepAlive> <!-- KeepAlive сохранит стейт вкладок при переключении -->
        <component :is="currentTab" :user="currentUser" />
      </KeepAlive>
    </div>
  </div>
</template>

<script setup>
import { shallowRef } from 'vue'

// Импортируем компоненты вкладок
import ProfileTab from './components/ProfileTab.vue'
import SettingsTab from './components/SettingsTab.vue'
import BillingTab from './components/BillingTab.vue'

// Создаем объект-маппинг для удобного перебора кнопок
const tabsMap = {
  'Профиль': ProfileTab,
  'Настройки': SettingsTab,
  'Счета': BillingTab
}

// Инициализируем текущую вкладку. ОБЯЗАТЕЛЬНО shallowRef!
const currentTab = shallowRef(ProfileTab)

// Какие-то данные, которые мы прокидываем внутрь табов
const currentUser = { name: 'Алиса', plan: 'Pro' }
</script>

<style scoped>
.active { font-weight: bold; border-bottom: 2px solid blue; }
</style>
```

**Резюме для React-разработчика:**
`<component :is="...">` — это декларативный способ отрендерить динамическую переменную как HTML-тег или Компонент. В связке с `shallowRef` это идеальный паттерн для табов, визардов и рендеринга UI на основе JSON-ответов от API. А вместе с `<KeepAlive>` это работает даже мощнее, чем стандартный условный рендер в React.
