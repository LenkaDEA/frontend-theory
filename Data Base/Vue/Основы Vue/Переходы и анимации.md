### Концепция и Теория

**Какую задачу это решает?**
Плавная анимация элементов в тот момент, когда они добавляются в DOM, удаляются из DOM или перемещаются в списках. 

**Как работает «под капотом»:**
Когда элемент внутри `<Transition>` появляется или исчезает (из-за `v-if`, `v-show` или динамического компонента), Vue "перехватывает" процесс работы с DOM.
Вместо того чтобы мгновенно удалить элемент, Vue:
1. Добавляет специальные CSS-классы начала анимации (например, чтобы сделать `opacity: 0`).
2. Отрисовывает кадр, затем добавляет классы активной анимации (где прописан `transition: opacity 0.5s`).
3. Слушает нативные события браузера `transitionend` или `animationend`.
4. Только после завершения CSS-анимации Vue физически удаляет элемент из DOM.

Для списков (`<TransitionGroup>`) Vue дополнительно использует технику под названием **FLIP** под капотом, чтобы плавно анимировать перемещение элементов (когда их сортируют или удаляют соседей).

### Синтаксис и База

Во Vue есть два встроенных компонента. Вы задаете им пропс `name`, а Vue автоматически генерирует для вас 6 CSS-классов.

- **`<Transition>`** — для одиночных элементов (модалки, тултипы, переключение вкладок).
- **`<TransitionGroup>`** — для списков (анимация внутри `v-for`).

Если вы написали `<Transition name="fade">`, вам нужно в CSS написать:
- `.fade-enter-active`, `.fade-leave-active` (здесь пишем сам `transition: all 0.3s ease`).
- `.fade-enter-from`, `.fade-leave-to` (начальное состояние при появлении и конечное при исчезновении, например `opacity: 0`).
- (*Классы `-enter-to` и `-leave-from` обычно не пишут, они подразумевают нормальное состояние элемента, которое и так у него есть*).

### Сравнение с React (Аналогии и Отличия)

* **Что мы делаем в React:**
  В чистом React невозможно анимировать демонтирование компонента. Как только `isOpen === false`, компонент исчезает. Чтобы это обойти, мы устанавливаем `react-transition-group` или тяжеловесный `Framer Motion` (с его `<AnimatePresence>`).

* **Что мы делаем во Vue:**
  Во Vue аналог `<AnimatePresence>` встроен в язык. Вы просто оборачиваете элемент в `<Transition>` и пишете 5 строчек обычного CSS. Не нужно учить сложные API сторонних библиотек.

* **JS-анимации:**
  И React (через Framer), и Vue поддерживают сложные анимации на JS (GSAP и т.д.). Во Vue для этого у `<Transition>` есть хуки-события: `@enter`, `@leave`, куда можно прокинуть JS-функцию для анимации.

### 4. Важные нюансы (Где можно выстрелить в ногу)

1. **Единственный корневой элемент:**
   Внутри `<Transition>` в один момент времени должен рендериться только **один** корневой элемент. Если вы хотите переключаться между двумя `div`, используйте `v-if` / `v-else`.

2. **Атрибут `mode="out-in"`:**
   Если вы переключаете два элемента (`v-if="isLogin"` / `v-else`), по умолчанию Vue будет анимировать их *одновременно* (один появляется, другой исчезает). Это часто ломает верстку. Добавьте `<Transition mode="out-in">`, и Vue сначала дождется полного исчезновения старого элемента, а только потом начнет показывать новый.

3. **Обязательный `key` для `<TransitionGroup>`:**
   Чтобы Vue понимал, какой элемент в списке куда двигается, на элементах внутри `<TransitionGroup>` **строго обязателен** уникальный атрибут `:key` (индекс массива не подойдет!).

4. **Класс `*-move` для списков:**
   У `<TransitionGroup>` есть дополнительный CSS-класс: `.name-move`. Если прописать в нем `transition: transform 0.5s`, элементы списка будут плавно "переезжать" на новые места при удалении или сортировке соседних элементов!

### Пример для заметок

Здесь мы совместим обе фичи: простую анимацию появления текста (`<Transition>`) и сложную анимацию списка (`<TransitionGroup>`).

```vue
<template>
  <div class="animations-demo">
    
    <!-- 1. TRANSITION (Одиночный элемент) -->
    <button @click="showMsg = !showMsg">Переключить сообщение</button>
    
    <!-- Имя "fade" преобразуется в классы .fade-enter-active и т.д. -->
    <Transition name="fade">
      <div v-if="showMsg" class="message">
        Привет, я плавно появляюсь и исчезаю!
      </div>
    </Transition>

    <hr />

    <!-- 2. TRANSITION GROUP (Список элементов) -->
    <button @click="addItem">Добавить элемент</button>
    <button @click="shuffleList">Перемешать</button>

    <!-- tag="ul" означает, что сам TransitionGroup отрендерится как тег <ul> -->
    <TransitionGroup name="list" tag="ul" class="my-list">
      <li 
        v-for="item in items" 
        :key="item.id" 
        @click="removeItem(item.id)"
      >
        {{ item.text }} (Кликни, чтобы удалить)
      </li>
    </TransitionGroup>

  </div>
</template>

<script setup>
import { ref } from 'vue'

const showMsg = ref(false)
const items = ref([
  { id: 1, text: 'Элемент 1' },
  { id: 2, text: 'Элемент 2' },
  { id: 3, text: 'Элемент 3' },
])
let nextId = 4

const addItem = () => {
  const randomIndex = Math.floor(Math.random() * items.value.length)
  items.value.splice(randomIndex, 0, { id: nextId++, text: `Новый ${nextId - 1}` })
}

const removeItem = (id) => {
  items.value = items.value.filter(i => i.id !== id)
}

const shuffleList = () => {
  items.value.sort(() => Math.random() - 0.5)
}
</script>

<style scoped>
/* --- Стили для <Transition name="fade"> --- */
.fade-enter-active,
.fade-leave-active {
  transition: opacity 0.5s ease;
}
/* Начало появления и конец исчезновения */
.fade-enter-from,
.fade-leave-to {
  opacity: 0;
}

/* --- Стили для <TransitionGroup name="list"> --- */
.list-enter-active,
.list-leave-active {
  transition: all 0.5s ease;
}
.list-enter-from,
.list-leave-to {
  opacity: 0;
  transform: translateX(30px); /* Выезжает/уезжает вправо */
}

/* МАГИЯ ВУЕ: Плавное перемещение остальных элементов (FLIP-анимация) */
.list-move {
  transition: transform 0.5s ease;
}

/* Чтобы элемент плавно освобождал место при удалении, 
   его нужно вырвать из потока (абсолютное позиционирование) */
.list-leave-active {
  position: absolute;
}

/* Косметика списка */
.my-list {
  position: relative;
  list-style-type: none;
  padding: 0;
}
.my-list li {
  padding: 10px;
  background: #eee;
  margin-bottom: 5px;
  cursor: pointer;
  width: 300px;
}
</style>
```

**Резюме для React-разработчика:**
Vue делает анимации невероятно приятными. Никаких `AnimatePresence`, никаких сложных расчетов стейта перед анмаунтом. Вы просто используете декларативные теги `<Transition>` и пишете стандартные CSS-переходы. Vue сам берет на себя всю грязную работу с таймингами и удалением узлов из DOM.
