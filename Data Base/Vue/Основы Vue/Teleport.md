### Концепция и Теория

**Какую задачу это решает?**
Логически компонент может находиться глубоко внутри дерева компонентов (например, кнопка «Открыть профиль» в шапке сайта). Но визуально этот компонент должен отрисовать элемент, который перекрывает весь экран (модальное окно, tooltip, dropdown, notification). 

Если модальное окно останется в DOM-дереве глубоко внутри других `div`, оно может быть обрезано родительским `overflow: hidden`, сломано `z-index` или CSS-трансформациями. `Teleport` позволяет "вырвать" кусок HTML из текущего места и отрендерить его совершенно в другом месте DOM-дерева (например, прямо перед `</body>`), при этом сохраняя логическую связь с родительским компонентом Vue.

**Как работает «под капотом»:**
Vue создает VNodes (виртуальные узлы) для телепортируемого контента, но на этапе "патчинга" (patching) реального DOM он берет эти элементы и физически через `appendChild` или `insertBefore` вставляет их в указанный целевой контейнер. При этом логическая связь (пропсы, события, контекст) остается нетронутой: компонент внутри Teleport продолжает работать так, будто он никуда не уезжал.

### Синтаксис и База

Это встроенный компонент, его не нужно импортировать. Вы просто оборачиваете нужный кусок шаблона в `<Teleport>` и указываете пропс `to` (куда телепортировать).

```html
<Teleport to="body">
  <div class="modal">...</div>
</Teleport>
```

Пропс `to` принимает валидный CSS-селектор:
- `"body"` (чаще всего)
- `"#modals-container"`
- `".toast-wrapper"`

### Сравнение с React (Аналогии и Отличия)

 - **`Teleport` = `ReactDOM.createPortal()`**
 - **Синтаксис (Удобство Vue):**
	 - **В React:** Создание портала требует вызова функции из пакета `react-dom`. Вам нужно написать что-то вроде: 
	    `return ReactDOM.createPortal(<MyModal />, document.getElementById('modal-root'));`

- **Во Vue:** Это сделано декларативно на уровне шаблона. Вы просто используете тег `<Teleport>`. Не нужно импортировать функции работы с DOM, всё выглядит как обычный HTML.

- **Отключение телепортации:**
  Во Vue у Teleport есть встроенный пропс `disabled`. Если `<Teleport to="body" :disabled="true">`, контент останется ровно там, где он написан в коде. В React для такого поведения пришлось бы писать условный рендер (если true — возвращаем портал, если false — просто компонент).

### Важные нюансы (Где можно выстрелить в ногу)

1. **Целевой элемент должен существовать в DOM:**
   Когда компонент с `<Teleport to="#modals">` монтируется, элемент `<div id="modals"></div>` **уже должен быть в HTML-документе**. Если Vue его не найдет, он выбросит предупреждение в консоль, а контент не отрисуется. (Обычно этот контейнер добавляют прямо в `index.html` рядом с `<div id="app">`).

2. **Множественные телепорты в одну цель:**
   Вы можете телепортировать несколько разных компонентов в один и тот же контейнер (например, несколько разных модалок в `body`). Vue просто добавит их туда по очереди, один за другим.

3. **Состояние компонента не теряется:**
   Даже если элемент физически улетел в `body`, он всё ещё часть дерева Vue. Если вы прокинули в модалку данные через `Provide`, или обращаетесь к ней через `ref`, всё будет работать идеально.

### Пример для заметок

В этом примере мы создадим кнопку, которая логически находится глубоко в макете, но открывает модалку на уровне `body`.

```vue
<template>
  <div class="deep-nested-component">
    <h3>Настройки профиля</h3>
    <button @click="isModalOpen = true">Удалить аккаунт</button>

    <!-- 
      Телепортируем модалку прямо в <body>.
      Даже если у .deep-nested-component стоит overflow: hidden, 
      модалка отобразится корректно на весь экран.
    -->
    <Teleport to="body">
      <!-- 
        v-if здесь важен: модалка не будет рендериться (даже в body), 
        пока isModalOpen равен false.
      -->
      <div v-if="isModalOpen" class="modal-overlay">
        <div class="modal-content">
          <h2>Вы уверены?</h2>
          <p>Это действие нельзя отменить.</p>
          
          <!-- Кнопка внутри телепорта имеет доступ к стейту компонента! -->
          <button @click="isModalOpen = false">Отмена</button>
        </div>
      </div>
    </Teleport>
  </div>
</template>

<script setup>
import { ref } from 'vue'

const isModalOpen = ref(false)
</script>

<style scoped>
/* Локальные стили. Но будьте осторожны! 
   Если модалка телепортируется в body, стили с атрибутом scoped 
   к ней тоже применятся (Vue добавит дата-атрибуты к элементам модалки 
   до того, как их телепортирует).
*/
.modal-overlay {
  position: fixed;
  top: 0; left: 0; right: 0; bottom: 0;
  background: rgba(0, 0, 0, 0.5);
  display: flex;
  align-items: center;
  justify-content: center;
  z-index: 9999;
}
.modal-content {
  background: white;
  padding: 20px;
  border-radius: 8px;
}
</style>
```

**Резюме для React-разработчика:**
`<Teleport to="selector">` — это `ReactDOM.createPortal()`, но сделанный красиво, декларативно и прямо в разметке. Используйте для всего, что должно «всплывать» поверх интерфейса: модалки, дропдауны, тосты-уведомления.
