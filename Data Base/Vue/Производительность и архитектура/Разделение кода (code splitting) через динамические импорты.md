#### 📝 Определение
**Разделение кода (Code Splitting)** — это техника оптимизации, при которой весь JavaScript-код приложения разбивается на несколько небольших файлов (чанков/chunks), вместо того чтобы собираться в один огромный `bundle.js`. 

**Динамический импорт** (`import()`) — это механизм JavaScript (не только Vue или React), который позволяет загружать модули асинхронно, прямо во время выполнения кода, только тогда, когда они действительно нужны.

**Зачем это нужно?** Чтобы пользователь не скачивал мегабайты JS-кода при заходе на главную страницу, если 90% этого кода относится к админке или профилю, куда он, возможно, даже не зайдет. Это кардинально ускоряет первоначальную загрузку (Time to Interactive).

#### ⚖️ Сравнение с React
Здесь подходы в React и Vue практически идентичны, так как в основе лежит один и тот же стандарт JavaScript и работа сборщиков (Vite, Webpack).

*   **React:** Для ленивой загрузки компонентов используется `React.lazy(() => import('./Component'))` в связке с `<Suspense>`. Для ленивой загрузки обычных функций/модулей — просто `import()`.
*   **Vue:** Для ленивой загрузки компонентов используется `defineAsyncComponent(() => import('./Component'))` (это мы разберем в следующей теме). Для роутинга и обычных модулей — просто `import()`.

#### 🛠 Как использовать (Примеры)

Чаще всего динамические импорты во Vue используются в двух местах: в **Vue Router** (для загрузки страниц по частям) и для **обычных тяжелых функций/библиотек**.

**Пример 1: Ленивая загрузка страниц в Vue Router (Самый частый кейс)**

Вместо того чтобы импортировать все страницы статически вверху файла `router.js`, мы импортируем их динамически прямо в определении маршрута.

*Плохо (Статический импорт - всё грузится сразу):*
```javascript
import Home from './views/Home.vue'
import Dashboard from './views/Dashboard.vue' // Тяжелая страница с графиками

const routes = [
  { path: '/', component: Home },
  { path: '/dashboard', component: Dashboard } 
]
```

*Хорошо (Динамический импорт - Code Splitting):*
```javascript
import Home from './views/Home.vue' // Главную загружаем сразу

const routes = [
  { path: '/', component: Home },
  { 
    path: '/dashboard', 
    // Vite/Webpack создаст отдельный файл (chunk) для Dashboard.vue
    // Он скачается только когда пользователь перейдет по ссылке /dashboard
    component: () => import('./views/Dashboard.vue') 
  } 
]
```

**Пример 2: Ленивая загрузка тяжелой библиотеки по клику**

Допустим, у нас есть кнопка "Экспорт в PDF", которая использует тяжелую библиотеку `html2pdf`. Нам не нужно грузить ее всем пользователям, ведь нажмут на кнопку единицы.

```html
<script setup>
const exportToPdf = async () => {
  // Динамически загружаем библиотеку только в момент вызова функции
  // Браузер сделает сетевой запрос за файлом библиотеки
  const html2pdf = (await import('html2pdf.js')).default
  
  const element = document.getElementById('report')
  html2pdf().from(element).save()
}
</script>

<template>
  <div id="report">...много данных...</div>
  <button @click="exportToPdf">Скачать PDF</button>
</template>
```

#### ⚠️ Особенности и ловушки (Pitfalls) для собеседования

1. **"Волшебные комментарии" (Magic Comments) в Webpack / Vite:**
   Сборщики позволяют группировать чанки или давать им понятные имена.
   *В Webpack:* `import(/* webpackChunkName: "dashboard" */ './Dashboard.vue')`.
   *В Vite (Rollup):* Vite делает это автоматически довольно умно, но если нужно, можно использовать конфигурацию `manualChunks` в `vite.config.js`. На собеседовании круто упомянуть, что ты знаешь, как контролировать имена чанков.

2. **Проблема "водопада" (Waterfall) при загрузке:**
   Если внутри динамически загружаемого компонента `Dashboard.vue` есть еще один динамический импорт (например, тяжелый график), браузер сначала скачает `Dashboard`, распарсит его, увидит второй импорт, и только потом пойдет качать график. Это замедляет отрисовку.
   *Решение:* Старайся не делать глубоких вложенных динамических импортов без необходимости, или используй предзагрузку (Prefetch).

3. **Обработка ошибок сети:**
   Что если пользователь нажал на ссылку `/dashboard`, браузер попытался скачать чанк через `import()`, но интернет пропал?
   В Vue Router есть глобальный обработчик `router.onError()`, где можно поймать ошибку загрузки чанка (часто это `ChunkLoadError`) и, например, перезагрузить страницу или показать уведомление "Проверьте соединение".
