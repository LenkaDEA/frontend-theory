
### `router-link` и `router-view`

Это два глобальных компонента, которые Vue Router автоматически регистрирует в твоем приложении, когда ты вызываешь `app.use(router)`. Их не нужно импортировать в каждый файл.

---

#### 1. `<router-link>` (Аналог `<Link>` и `<NavLink>` в React)

Этот компонент используется для навигации. В браузере он рендерится как обычный HTML-тег `<a>`. 

**Почему нельзя просто использовать тег `<a>`?**
Если ты используешь `<a href="/about">`, браузер отправит запрос на сервер и **полностью перезагрузит страницу**. 
`<router-link>` перехватывает клик, отменяет стандартное поведение браузера (перезагрузку) и вызывает `router.push()` под капотом, чтобы интерфейс обновился мгновенно через JS.

**Важные атрибуты:**

*   **`to` (Обязательный):** Куда ведет ссылка. Может принимать строку или объект (как мы уже обсуждали).
```html
<router-link to="/about">О нас</router-link>
<router-link :to="{ name: 'UserProfile', params: { id: 1 } }">Профиль</router-link>
```

*   **`replace`:** Если добавить этот атрибут, при клике сработает `router.replace()` вместо `push` (то есть страница не попадет в историю браузера).
```html
<router-link to="/dashboard" replace>На дашборд</router-link>
```

*   **[Активные классы](Активные%20классы.md) (Очень важно!):**
    В React Router есть разделение: `<Link>` просто ссылка, а `<NavLink>` добавляет класс `active`, если URL совпадает. Во Vue `<router-link>` умеет это делать сразу.
    
    Когда URL в браузере совпадает с атрибутом `to`, Vue Router автоматически вешает на ссылку CSS-класс:
    *   `router-link-active` — вешается при **частичном** совпадении. (Например, URL `/users/123`, ссылка на `/users` получит этот класс).
    *   `router-link-exact-active` — вешается только при **полном (точном)** совпадении.

    *Как использовать?* Просто пиши CSS для этих классов, чтобы подсветить активный пункт меню:
```css
/* В твоем CSS файле */
.router-link-exact-active {
  color: red;
  font-weight: bold;
}
```

#### 2. `<router-view>` (Аналог `<Outlet>` в React)

Это "окно", через которое роутер показывает компонент, соответствующий текущему URL.

**Особенности, которые нужно знать (продвинутый уровень):**

Иногда на собеседовании могут спросить: *"Как сделать так, чтобы при переходе между маршрутами была плавная анимация (transition)?"* или *"Как сохранить состояние компонента (чтобы не сбрасывался скролл или введенный текст), если мы ушли на другую страницу и вернулись?"*

В React это делается через сложные сторонние библиотеки (типа Framer Motion) или ручное управление стейтом. Во Vue это встроено в экосистему благодаря компонентам `<Transition>` и `<KeepAlive>`. 

Но в **Vue Router 4** (для Vue 3) синтаксис их использования с `<router-view>` изменился по сравнению с Vue 2. Теперь нужно использовать `v-slot` (scoped slots).

**Анимация переходов:**
```html
<router-view v-slot="{ Component }">
  <!-- Оборачиваем компонент в Transition для анимации -->
  <transition name="fade" mode="out-in">
    <!-- Component - это текущий компонент маршрута -->
    <component :is="Component" />
  </transition>
</router-view>
```

**Кеширование состояния (KeepAlive):**
Если мы не хотим, чтобы компонент уничтожался при уходе с роута (например, там длинная форма, которую юзер еще не заполнил):
```html
<router-view v-slot="{ Component }">
  <keep-alive>
    <component :is="Component" />
  </keep-alive>
</router-view>
```

*(Эта комбинация `router-view`, `v-slot` и `<component :is="...">` — частый вопрос на знание современного Vue 3).*

---

**Резюме для собеса по этой теме:**
1. `<router-link>` предотвращает перезагрузку страницы (SPA-поведение) и рендерится как тег `<a>`.
2. Он автоматически добавляет классы активности (`router-link-active` и `router-link-exact-active`), что заменяет компонент `<NavLink>` из React.
3. `<router-view>` — это место рендера (аналог `<Outlet>`).
4. Для анимаций и кеширования страниц с `<router-view>` в Vue 3 используется паттерн `v-slot="{ Component }"`.
