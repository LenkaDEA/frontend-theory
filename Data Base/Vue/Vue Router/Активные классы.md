### Что такое "Активные классы" во Vue Router?

Представь, что ты делаешь боковое меню (Sidebar). В нем есть ссылки:
* "Главная" (`/`)
* "Пользователи" (`/users`)
* "Настройки" (`/settings`)

Когда пользователь находится на странице `/users`, тебе нужно, чтобы пункт "Пользователи" в меню был подсвечен (например, стал жирным или поменял цвет фона), чтобы человек понимал, где он находится.

В обычном HTML/JS тебе пришлось бы писать логику: брать текущий URL, проверять, совпадает ли он с `href` ссылки, и если да, вручную вешать класс `class="active"`.

**Во Vue Router это происходит автоматически.**

Когда ты используешь `<router-link>`, Vue Router сам следит за URL в браузере. Если URL совпадает с тем, что написано в атрибуте `to`, Vue Router **автоматически добавляет CSS-классы** на этот тег.

Тебе остается только описать эти стили в CSS.

---

### Два встроенных класса

Vue Router добавляет сразу два разных класса, потому что "совпадение" URL бывает разным: частичным и полным.

#### 1. Класс `router-link-exact-active` (Полное совпадение)
Этот класс добавляется **только** если URL в браузере *на 100% точно* совпадает с атрибутом `to` в ссылке.

**Пример:**
URL в браузере: `yoursite.com/users`
Твои ссылки:
* `<router-link to="/users">` 👉 **Получит** класс `router-link-exact-active`
* `<router-link to="/users/123">` 👉 **Не получит** класс

*Для чего нужен:* Для подсветки конкретного, конечного пункта меню.

#### 2. Класс `router-link-active` (Частичное совпадение)
Этот класс добавляется, если текущий URL *начинается* с того, что указано в атрибуте `to`.

**Пример:**
URL в браузере: `yoursite.com/users/123/profile` (мы находимся в профиле конкретного пользователя).
Твои ссылки в главном меню:
* `<router-link to="/users">` 👉 **Не получит** exact-active (потому что полное совпадение не сработало), **НО ПОЛУЧИТ** `router-link-active`.

*Для чего нужен:* Это супер-удобно для подсветки родительских категорий! Если ты провалился глубоко в карточку пользователя (`/users/123`), пункт меню "Пользователи" (`/users`) все равно останется подсвеченным, показывая активный раздел приложения.

---

### Как это использовать на практике?

В коде компонента ты просто пишешь ссылки:
```html
<nav>
  <router-link to="/">Главная</router-link>
  <router-link to="/users">Пользователи</router-link>
  <router-link to="/settings">Настройки</router-link>
</nav>
```

А в теге `<style>` пишешь CSS для этих встроенных классов:
```css
/* Делаем ссылки черными по умолчанию */
nav a {
  color: black;
  text-decoration: none;
}

/* Если роутер повесил этот класс, делаем текст синим и жирным */
.router-link-active {
  color: blue;
  font-weight: bold;
}
```

### Сравнение с React

В React Router v6 обычный `<Link>` так не умеет. Тебе нужно использовать специальный компонент `<NavLink>`, который принимает функцию в пропс `className` или `style`:

```jsx
// React Router
<NavLink 
  to="/users" 
  className={({ isActive }) => isActive ? "active-link" : ""}
>
  Пользователи
</NavLink>
```

Во Vue это работает "из коробки" прямо на базовом `<router-link>`, без дополнительных проверок и функций. Тебе нужно только знать названия этих двух классов (`router-link-active` и `router-link-exact-active`) и написать для них CSS.
