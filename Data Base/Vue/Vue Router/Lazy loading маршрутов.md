Lazy loading (Ленивая загрузка) маршрутов — это важнейшая тема для производительности. Если об этом не позаботиться, весь код твоего приложения скомпилируется в один гигантский JS-бандл. Пользователю придется скачивать мегабайты кода (включая код страницы админки, на которую он никогда не зайдет), прежде чем он увидит хотя бы главную страницу.

И во Vue, и в React эта проблема решается с помощью динамического импорта (`import()`), но синтаксис настройки немного отличается.
#### Как это работает во Vue

Вместо того чтобы импортировать компонент статически в начале файла:
```javascript
// ПЛОХО (Статический импорт - всё попадет в один бандл)
import Home from '../views/Home.vue'
import Dashboard from '../views/Dashboard.vue'

const routes = [
  { path: '/', component: Home },
  { path: '/dashboard', component: Dashboard }
]
```

Мы передаем в свойство `component` **функцию, которая возвращает динамический импорт**:

```javascript
// ХОРОШО (Ленивая загрузка - сборщик разобьет код на куски)
const routes = [
  { 
    path: '/', 
    // Загружаем сразу, если это главная страница, которую видят все
    component: () => import('../views/Home.vue') 
  },
  { 
    path: '/dashboard', 
    // Этот код загрузится из сети ТОЛЬКО когда пользователь перейдет на /dashboard
    component: () => import('../views/Dashboard.vue') 
  }
]
```

Когда сборщик (Vite или Webpack) видит конструкцию `() => import(...)`, он понимает: "Ага, этот файл нужно положить в отдельный `.js` чанк". Когда Vue Router пытается перейти на этот маршрут, он выполняет эту функцию, браузер делает сетевой запрос за нужным куском JS, и только после его загрузки компонент рендерится.

#### Сравнение с React

В React этот процесс чуть более многослойный (хотя концепция та же). Тебе нужно использовать `React.lazy` для компонента и обернуть место рендера в `<Suspense>`, чтобы показать fallback (например, лоадер), пока код грузится.

```javascript
// React
import { lazy, Suspense } from 'react';

// 1. Создаем ленивый компонент
const Dashboard = lazy(() => import('./views/Dashboard'));

const router = createBrowserRouter([
  { 
    path: "/dashboard", 
    // 2. Оборачиваем в Suspense
    element: (
      <Suspense fallback={<div>Loading...</div>}>
        <Dashboard />
      </Suspense>
    ) 
  }
]);
```

Во Vue Router это скрыто "под капотом". Тебе не обязательно писать аналог `<Suspense>` для роутера (хотя Vue тоже поддерживает встроенный `<Suspense>`, обычно роутер сам дожидается загрузки чанка и только потом переключает страницу).

#### 🚨 Важный нюанс для собеса: Группировка чанков

Иногда на собеседовании (особенно на мидла/синьора) могут спросить: *"А что если у нас в папке `/admin` лежит 10 компонентов, и мы хотим, чтобы они скачивались не по одному, а все вместе одним файлом, когда юзер заходит в админку?"*

**Решение для Webpack (Магические комментарии):**
Если твой проект использует Webpack, ты можешь использовать `/* webpackChunkName: "name" */`:
```javascript
const routes = [
  {
    path: '/admin/users',
    component: () => import(/* webpackChunkName: "admin-group" */ '../views/AdminUsers.vue')
  },
  {
    path: '/admin/settings',
    component: () => import(/* webpackChunkName: "admin-group" */ '../views/AdminSettings.vue')
  }
]
```
В этом случае Webpack скомпилирует оба этих компонента в один файл `admin-group.js`.

**Решение для Vite (Rollup):**
Если используешь современный Vite (что сейчас стандарт для Vue), магия Webpack не сработает. Там группировка настраивается в конфигурации сборщика (`vite.config.js` -> `build.rollupOptions.output.manualChunks`).

---

**Резюме для собеса по этой теме:**
1. Ленивая загрузка нужна для **Code Splitting** (разделения кода на мелкие чанки), чтобы уменьшить начальный размер бандла.
2. Во Vue это делается передачей функции `() => import('./Component.vue')` прямо в свойство `component` роута.
3. В React для этого требуются `React.lazy` и обертка `<Suspense>`.
4. Для оптимизации загрузки связанных страниц можно группировать чанки.
