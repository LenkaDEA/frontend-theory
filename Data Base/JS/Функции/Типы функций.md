# Function Declaration (Объявление функции)

Самый классический способ. Такую функцию можно вызвать в коде до того, как она описана.
```js
sayHello(); // Работает!

function sayHello() {
  console.log("Привет!");
}
```
- **Главная фишка: Hoisting (Всплытие).** Интерпретатор «поднимает» такие функции в начало области видимости перед выполнением кода. Ты можешь вызвать функцию _до_ того, как она описана в коде.

- **Область видимости:** Блочная (в строгом режиме) или функциональная.
# Function Expression (Функциональное выражение)

Функция создается внутри выражения и обычно присваивается переменной. Она не «поднимается», поэтому вызвать её можно только после объявления.
```JS
const sum = function(a, b) {
  return a + b;
};
```
- **Hoisting:** Не всплывает. К переменной применяется правило «Temporal Dead Zone» (зависит от `let`/`const`). Вызвать функцию можно только _после_ строки с объявлением.

- **Использование:** Удобно для передачи функций в качестве аргументов (callbacks) или создания анонимных функций.
# Arrow Functions (Стрелочные функции)

Появились в ES6. У них более короткий синтаксис и, что важно, нет своего контекста this (они берут его из окружения).
```js
const multiply = (a, b) => a * b;
```

**Что обязательно спросят на собеседовании:**

- **Отсутствие своего `this`:** Они не создают собственного контекста, а берут его из внешней среды (лексический `this`). Это делает их идеальными для методов внутри классов React или для `setTimeout`.

- **Нет объекта `arguments`:** Вместо этого нужно использовать rest-оператор `(...args)`.

- **Нельзя использовать как конструктор:** Вызов стрелочной функции через `new` вызовет ошибку.

- **Нет метода `super` и объекта `new.target`.**

### Named Function Expression (NFE)

Разновидность выражения, где у функции есть имя.

```JavaScript
const factorial = function func(n) {
  return n <= 1 ? 1 : n * func(n - 1);
};
```

- **Зачем нужно:** Имя `func` доступно только _внутри_ самой функции. Это полезно для рекурсии и делает стек вызовов (Stack Trace) более понятным при отладке.
# IIFE (Immediately Invoked Function Expression)

Функция, которая выполняется сразу после того, как была определена. Часто используется для создания локальной области видимости.
```js
(function() {
  console.log("Я запустилась сама!");
})();
```

# Anonymous Functions (Анонимные функции)

Функции без имени. Обычно используются как аргументы в методах массивов или колбэках.
```js
setTimeout(function() {
  console.log("Прошла 1 секунда");
}, 1000);
```

# Generator Functions (Функции-генераторы)

Могут приостанавливать свое выполнение и возвращать промежуточные результаты с помощью ключевого слова yield.
```js
function* count() {
  yield 1;
  yield 2;
  return 3;
}
```

Важно помнить еще про контекст функций (this).

### Что отвечать на вопрос: «Что выбрать?»

- Используй **Arrow Functions** для методов внутри компонентов/классов, где важен контекст, и для коротких callback-функций.

- Используй **Function Declaration** для функций верхнего уровня, которые должны быть доступны во всем файле, или если тебе нужен динамический `this`.

- Используй **NFE**, если пишешь сложную рекурсивную логику, чтобы облегчить дебаг.
