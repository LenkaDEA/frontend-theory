**IIFE** (произносится как «ифи») — это функция, которая выполняется сразу же после того, как она была определена.
### Синтаксис

Чтобы превратить обычную функцию в IIFE, её нужно обернуть в группирующие скобки `()` (превратив в выражение) и сразу вызвать второй парой скобок.

```JavaScript
(function() {
  const message = "Я работаю сразу!";
  console.log(message);
})();
```

**Вариант со стрелочной функцией:**

```JavaScript
(() => {
  console.log("IIFE на стрелках");
})();
```

---
### Зачем нужны IIFE? (Ключевые причины)

#### 1. Изоляция области видимости (Encapsulation)

Это была основная цель до появления `let`, `const` и модулей. Любые переменные, объявленные внутри IIFE, не «загрязняют» глобальный объект (`window` или `global`).

- _На собеседовании:_ Скажи, что это предотвращает конфликты имен в больших проектах или при подключении сторонних библиотек.

#### 2. Создание приватных переменных (через замыкание)

IIFE часто используется для реализации паттерна «Модуль», где часть данных скрыта, а часть доступна снаружи.

```JavaScript
const counter = (function() {
  let count = 0; // Приватная переменная

  return {
    increment: () => ++count,
    reset: () => { count = 0; }
  };
})();
```

#### 3. Избежание проблем с `var` в циклах

Как мы обсуждали в теме «Замыкания», IIFE помогает зафиксировать значение переменной на каждой итерации.

---
### Важные нюансы для Senior-позиции:

- **Точка с запятой `;` перед IIFE:** Ты часто можешь увидеть код, начинающийся с `;(function...`. Это «защитная» точка с запятой. Она нужна, если предыдущий файл или строка кода не закончились точкой с запятой, чтобы интерпретатор не попытался вызвать результат предыдущей строки как функцию.

- **Передача параметров:** В IIFE можно передавать аргументы. Это часто использовалось для сокращения имен глобальных переменных (например, передать `jQuery` и внутри использовать как `$`).

```JavaScript
(function($, global) {
  // работаем с $
})(jQuery, window);
```

### Почему мы используем их реже сейчас?

С появлением **ES6 Modules** (`export/import`) каждый файл и так имеет свою изолированную область видимости. А блочная область видимости `{ let x = 1; }` позволяет скрывать переменные без создания лишних функций.
