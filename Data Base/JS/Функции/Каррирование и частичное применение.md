### 1. Каррирование (Currying)

**Определение:** Это трансформация функции с множеством аргументов в серию функций, каждая из которых принимает ровно **один** аргумент.

Вместо `f(a, b, c)` мы получаем `f(a)(b)(c)`.

**Пример реализации:**

```JavaScript
// Обычная функция
const sum = (a, b) => a + b;

// Каррированная версия
const curriedSum = (a) => (b) => a + b;

console.log(curriedSum(5)(10)); // 15
```

**Зачем это нужно?**

- **Специализация функций:** Можно создать «базовую» функцию и на её основе генерировать более узкие (например, функцию логирования с предустановленным уровнем `DEBUG` или `ERROR`).

- **Чистота кода:** Облегчает композицию функций.

---
### 2. Частичное применение (Partial Application)

**Определение:** Это процесс фиксации нескольких аргументов функции, что создает новую функцию с меньшим количеством аргументов.

В отличие от каррирования, частичное применение не обязано разбивать функцию строго по одному аргументу. Оно просто «предзаполняет» часть из них.

**Пример:**

```JavaScript
const multiply = (a, b, c) => a * b * c;

// Частичное применение через .bind()
const doubleAndMultiply = multiply.bind(null, 2); 

console.log(doubleAndMultiply(3, 4)); // 24 (2 * 3 * 4)
```

## В чем ключевая разница? (Важно для ответа)
| **Характеристика**     | **Каррирование**                                            | **Частичное применение**                                 |
| ---------------------- | ----------------------------------------------------------- | -------------------------------------------------------- |
| **Количество функций** | Создает цепочку функций (по одной на каждый аргумент).      | Создает одну новую функцию.                              |
| **Аргументы**          | Всегда **один** аргумент на каждом шаге.                    | Может фиксировать **любое количество** аргументов сразу. |
| **Результат**          | Функция возвращается, пока не будут переданы все аргументы. | Возвращается функция, ожидающая оставшиеся аргументы.    |
### Продвинутый уровень: Реализация универсального curry

Тебя могут попросить написать функцию `curry`, которая превращает любую функцию в каррированную.

```JavaScript
function curry(func) {
  return function curried(...args) {
    // Если количество переданных аргументов совпадает с ожидаемым в func
    if (args.length >= func.length) {
      return func.apply(this, args);
    } else {
      // Иначе возвращаем новую функцию, которая собирает аргументы дальше
      return function(...args2) {
        return curried.apply(this, args.concat(args2));
      }
    }
  };
}

// Использование
const totalSum = (a, b, c) => a + b + c;
const curried = curry(totalSum);

console.log(curried(1)(2)(3)); // 6
console.log(curried(1, 2)(3)); // 6 (гибкий вариант)
```

### Где это встречается в React?

Хотя в современном React (Hooks) это встречается реже, понимание каррирования помогает при создании обработчиков событий в списках:

```JavaScript
const handleChange = (id) => (event) => {
  console.log(`Field ${id} changed to:`, event.target.value);
};

// В рендере:
// <input onChange={handleChange('username')} />
```

Это избавляет от создания анонимных стрелочных функций прямо в `JSX` при каждом рендере.
