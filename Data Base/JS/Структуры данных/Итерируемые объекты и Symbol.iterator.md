### 1. Что такое Итерируемый объект (Iterable)?

**Итерируемый объект** — это объект, который предоставляет метод для перебора своего содержимого. В JavaScript итерируемыми по умолчанию являются: `Array`, `String`, `Map`, `Set`, `arguments`.

Чтобы объект стал итерируемым, он должен реализовать **протокол итерации**:

1. У объекта должен быть метод с ключом `Symbol.iterator`.
2. Этот метод должен возвращать **итератор** — объект с методом `.next()`.
3. Метод `.next()` должен возвращать объект вида `{ value: any, done: boolean }`.
---
### 2. Зачем это нужно?

Если объект реализует этот протокол, к нему можно применять:

- Цикл `for...of`
- Оператор расширения (spread) `[...]`
- Деструктуризацию `[a, b] = iterable`
- `Array.from(iterable)`

---

### 3. Реализация своего итерируемого объекта

Самый частый пример на собеседовании — создать объект «диапазон» (Range), который можно перебрать.

```JavaScript
const range = {
  from: 1,
  to: 5,

  // 1. Создаем метод Symbol.iterator
  [Symbol.iterator]() {
    // Он возвращает объект-итератор
    return {
      current: this.from,
      last: this.to,

      // 2. Метод next() вызывается на каждой итерации цикла for...of
      next() {
        if (this.current <= this.last) {
          return { done: false, value: this.current++ };
        } else {
          // Когда итерация завершена
          return { done: true };
        }
      }
    };
  }
};

for (let num of range) {
  console.log(num); // 1, 2, 3, 4, 5
}
```

### 4. Итерируемые объекты vs Псевдомассивы (Array-like)

Это критически важный вопрос. На нем часто пытаются подловить.

- **Итерируемые (Iterables):** Это объекты, реализующие `Symbol.iterator` (их можно перебрать `for...of`).
- **Псевдомассивы (Array-like):** Это объекты, у которых есть индексы (`0, 1, 2...`) и свойство `length`. Они выглядят как массивы, но у них нет методов массивов (`push`, `map`) и они не обязательно итерируемы.
> **Пример:** Обычный объект `{ 0: "a", 1: "b", length: 2 }` — это псевдомассив, но не итерируемый объект. **Пример:** Строка — и итерируемый объект, и псевдомассив. **Как превратить их в настоящий массив?** Использовать `Array.from()`. Этот метод умеет работать и с теми, и с другими.

### 🚩 Вопросы от «интервьюера»:

1. **«Что будет, если вызвать spread-оператор `[...]` на объекте, у которого нет Symbol.iterator?»**
   _Ответ:_ Будет ошибка `TypeError: object is not iterable`. (Исключение: литерал объекта `{...obj}` — это другой механизм, не использующий итераторы).

2. **«Можно ли вызвать Symbol.iterator вручную?»** 
   _Ответ:_ Да. Это обычный метод. Мы можем получить итератор и дергать `.next()` до тех пор, пока `done` не станет `true`. Это именно то, что делает `for...of` под капотом.

3. **«В чем профит итераторов для больших данных?»** 
   _Ответ:_ **Ленивые вычисления**. Итератор выдает значения по одному «по требованию». Нам не нужно создавать в памяти массив из миллиона элементов, чтобы просто по нему пройтись. Мы можем генерировать значения на лету.
