### 1. Rest-оператор (Сбор)

**Суть:** Собирает «остатки» элементов в настоящий массив. Используется там, где мы **объявляем** переменные или параметры.

- **В функциях:** Позволяет функции принимать неограниченное количество аргументов.
```JavaScript
function sum(...numbers) { // numbers — это полноценный массив
  return numbers.reduce((acc, n) => acc + n, 0);
}
```

- **В деструктуризации:** Собирает все оставшиеся свойства или элементы.

```JavaScript
const [first, ...rest] = [1, 2, 3, 4]; // rest = [2, 3, 4]
const { id, ...cleanUser } = { id: 1, name: 'Elena', role: 'admin' };
```

### 2. Spread-оператор (Расширение / Распространение)

**Суть:** «Распаковывает» элементы массива или свойства объекта в новое место. Используется там, где мы **передаем** или **создаем** данные.

- **Копирование и слияние:**

```JavaScript
const arrCopy = [...oldArr];
const mergedObj = { ...obj1, ...obj2 };
```

- **Передача в аргументы:**

```JavaScript
const nums = [5, 10, 1];
Math.max(...nums); // эквивалентно Math.max(5, 10, 1)
```

- **Строки:** Превращает строку в массив символов: `[...'Hi']` -> `['H', 'i']`.

### Что точно спросят на собеседовании (Senior-уровень)

#### 1. Rest vs Arguments

Это мы уже немного затронули в теме псевдомассивов, но повторим базу для ответа:

- `Rest` — это массив, `arguments` — нет.
- `Rest` работает в стрелочных функциях, `arguments` — нет.
- `Rest` более гибкий: он может собрать только часть аргументов, а `arguments` всегда содержит всё.

#### 2. Поверхностное копирование (Shallow Copy)

Это «ловушка номер один» в React.

```JavaScript
const original = { a: 1, b: { c: 2 } };
const copy = { ...original };
copy.b.c = 99;
console.log(original.b.c); // 99! 
```

**Вывод:** Spread копирует только первый уровень вложенности. Ссылки на вложенные объекты остаются прежними. Для глубокого копирования используем `structuredClone()` (современный стандарт) или библиотеки типа `lodash`.

#### 3. Порядок имеет значение (Object Merge)

Если в двух объектах есть одинаковые ключи, при использовании spread **побеждает тот, кто идет последним**.

```JavaScript
const user = { name: 'Elena', role: 'user' };
const admin = { ...user, role: 'admin' }; // role будет 'admin'
const fail = { role: 'admin', ...user };  // role будет 'user', так как spread затер значение
```

#### 4. Ограничение Rest-оператора

Rest-оператор **всегда** должен быть последним в списке деструктуризации или параметров функции. Код `const [...rest, last] = arr;` вызовет `SyntaxError`.
