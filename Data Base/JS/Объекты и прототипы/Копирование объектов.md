### 1. Поверхностное копирование (Shallow Copy)

Копирует только верхний уровень свойств. Если внутри объекта есть другие объекты или массивы, в новую копию попадут **ссылки** на них, а не сами данные.

- **Spread-оператор (`...`):** `const copy = { ...original };` (самый частый способ).
- **Object.assign:** `const copy = Object.assign({}, original);` (более старый способ).

**В чем подвох:**

```JavaScript
const user = { name: 'Elena', skills: ['JS', 'React'] };
const copy = { ...user };

copy.skills.push('Node'); 
console.log(user.skills); // ['JS', 'React', 'Node'] — оригинал тоже изменился!
```

### 2. Глубокое копирование (Deep Copy)

Создает полную копию всей структуры данных, включая все вложенные объекты.

#### Способ А: `structuredClone()` — Современный стандарт

Это встроенная функция (доступна в браузерах и Node.js 17+).

- **Плюсы:** Работает "из коробки", поддерживает циклические ссылки, правильно копирует `Date`, `Map`, `Set`, `ArrayBuffer`.
- **Минусы:** Не умеет копировать функции и методы объектов (выдаст ошибку `DataCloneError`).

#### Способ Б: `JSON.parse(JSON.stringify())` — "Дедовский" метод

- **Плюсы:** Работает везде.
- **Минусы (важно для интервью!):** * **Теряет данные:** свойства со значением `undefined`, функции, `Symbol` просто исчезают.
    - `Date` превращается в строку.
    - `NaN` и `Infinity` превращаются в `null`.
    - Падает на циклических ссылках.

#### Способ В: Рекурсия или библиотеки

Если нужно копировать функции или работать со сложной логикой, используют `_.cloneDeep` из Lodash или пишут свою рекурсивную функцию (на собеседованиях иногда просят написать простую версию).

### Что точно спросят на собеседовании

1. **"Как быстро сделать глубокую копию?"** 
	_Ответ:_ `structuredClone`, если нет функций. Если есть — Lodash или рекурсия.

2. **"Что будет, если в объекте есть циклическая ссылка, а мы делаем `JSON.stringify`?"** 
	*Ответ:* Будет ошибка `TypeError: Converting circular structure to JSON`.

3. **"Почему `const copy = { ...obj }` — это не всегда безопасно?"** 
	_Ответ:_ Потому что вложенные объекты остаются связанными по ссылке. Изменение вложенного объекта в копии затронет оригинал.

4. **"Как `structuredClone` ведет себя с методами объекта?"** 
	_Ответ:_ Выбрасывает исключение. Функции не могут быть клонированы этим алгоритмом.
