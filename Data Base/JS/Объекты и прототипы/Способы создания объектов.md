### 1. Объектный литерал (`{}`)

Самый частый и рекомендуемый способ.
```JavaScript
const user = { name: 'Elena' };
```

- **Особенности:** Краткость, лучшая читаемость.
- **Прототип:** Автоматически устанавливается в `Object.prototype`.
- **На заметку:** Движки (V8) лучше всего оптимизируют именно литералы.

### 2. Конструктор `Object` (через `new`)

```JavaScript
const obj = new Object();
obj.name = 'Elena';
```

- **Особенности:** Почти не используется в реальности. Считается плохим тоном, так как литерал короче и быстрее.
- **Интересный факт:** Если в `new Object(arg)` передать примитив (число, строку), он создаст объектную обертку (Wrapper) для этого типа.

### 3. Функция-конструктор

Классика до появления классов.

```JavaScript
function User(name) {
  this.name = name;
}
const user = new User('Elena');
```

- **Как работает `new` (важно для интервью!):**
    1. Создается пустой объект `{}`.
    2. Этому объекту устанавливается прототип (`__proto__`) из `User.prototype`.
    3. Вызывается функция `User`, при этом `this` указывает на этот новый объект.
    4. Если функция не возвращает другой объект, возвращается `this`.

### 4. Метод `Object.create(proto, descriptors)`

Позволяет создать объект и **явно** указать ему прототип.

```JavaScript
const animal = { eats: true };
const rabbit = Object.create(animal, {
  jumps: { value: true }
});
```

- **Любимый вопрос на собеседовании:** «Как создать объект, у которого вообще нет прототипа?»
    - **Ответ:** `Object.create(null)`. Такой объект не будет иметь даже базовых методов вроде `toString()` или `valueOf()`. Это полезно для создания чистых мап (словерей), чтобы ключи не конфликтовали со свойствами из `Object.prototype` (например, ключ `'hasOwnProperty'`).

### 5. Классы (ES6)

Современный стандарт.

```JavaScript
class User {
  constructor(name) {
    this.name = name;
  }
}
const user = new User('Elena');
```

- **Особенности:** Под капотом всё равно прототипы, но синтаксис строже. Например, класс нельзя вызвать без `new`.

#### Таблица сравнения
| **Способ**            | **Установка прототипа**    | **Когда использовать**                                                  |
| --------------------- | -------------------------- | ----------------------------------------------------------------------- |
| **Литерал `{}`**      | `Object.prototype`         | Всегда по умолчанию.                                                    |
| **`Object.create()`** | Вручную (первый аргумент)  | Когда нужно специфичное наследование или "чистый" объект без прототипа. |
| **`new Constructor`** | Из `Constructor.prototype` | В легаси-коде или простых архитектурах.                                 |
| **Классы**            | Из `Class.prototype`       | Современные приложения, React-компоненты (старые), сложные сущности.    |
### "Трюки" с копированием

Иногда под "созданием" подразумевают создание нового объекта на основе старого:
- `Object.assign({}, original)` — поверхностное копирование.
- `{ ...original }` (Spread) — современный стандарт поверхностного копирования.
- `structuredClone(original)` — современный встроенный метод для **глубокого** копирования (Deep Clone).
