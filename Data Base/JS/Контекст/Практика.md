1. Скрипт запущен в обычном режиме.
2. Скрипт запущен в `'use strict'`.

**Ответ:** 
в обычным режиме глобальный объект window или global. в use strict остается null или undefined

нет, нельзя, т.к. контекст уже намертво прибит bind. Единственный вариант создать ПУСТОЙ объект это использовать new

### Блок 2: Лайфкодинг (что выведет код?)

#### Задача №1: Потеря и стрелки

Посмотри на код и скажи, что будет в консоли. Как исправить ошибку, не меняя `setTimeout` на стрелку?

```JavaScript
const ladder = {
  step: 0,
  up() {
    this.step++;
    return this;
  },
  showStep() {
    console.log(this.step);
  }
};

ladder.up().up().showStep(); // Что выведет здесь?

const show = ladder.showStep;
setTimeout(show, 100); // А что выведет здесь через 100мс?
```


**Ответ:**
```js
const ladder = {
  step: 0,
  up() {
    this.step++;
    return this;
  },
  showStep() {
    console.log(this.step);
  }
};

ladder.up().up().showStep(); // Что выведет здесь? - 2

const show = ladder.showStep;
setTimeout(show, 100); // А что выведет здесь через 100мс? - undefined т.к. контекст потерялся.
```
Нам надо тогда написать 
```js
setTimeout(()=>{ladder.show}, 100);
```  
тогда мы сохраним контекст

ИЛИ прибить его намертво
```js
const show = ladder.showStep.bind(ladder)
setTimeout(show, 100);
```


#### Задача №2: Вложенные вызовы

Типичная задача на проверку того, как человек понимает границы контекста. Что будет в консоли?

```JavaScript
const group = {
  title: "Frontend Infrastructure",
  items: ["React", "TypeScript"],
  showList() {
    this.items.forEach(function(item) {
      console.log(`${this.title}: ${item}`);
    });
  }
};

group.showList();
```

**Ответ:**

колбек forEach имеет контект перед точкой items. но сам объект group он потеряет. Получится 
undefined: React undefined: TypeScript
чтоб этого не произошло можно использовать стрелочкную функцию
```js
showList() {
    this.items.forEach(item => {
      console.log(`${this.title}: ${item}`);
    });
  }
```


тогда контекст сохранится на момент создания
Или можно его прибить

```js
showList() {
    const myThis = this; // сохранили его
    this.items.forEach(function(item) {
      console.log(`${myThis.title}: ${item}`);
    });
  }
```

аргумент для прокидывания контекста
```js
showList() {
  this.items.forEach(function(item) {
    console.log(`${this.title}: ${item}`);
  }, this); // <-- Вот он! Мы явно передаем текущий this внутрь колбэка
}
```

через bind()
```js
showList() {
  this.items.forEach(function(item) {
    console.log(`${this.title}: ${item}`);
  }.bind(this)); // Привязали контекст к анонимной функции
}
```
