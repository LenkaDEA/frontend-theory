Эти методы позволяют нам вручную указать, какой объект должен быть использован в качестве `this`.

---
#### 1. Методы `call()` и `apply()`

Оба метода **вызывают функцию немедленно** с заданным контекстом.

- **`call(context, arg1, arg2, ...)`**: Аргументы передаются через запятую.
    - _Как запомнить:_ **C**all = **C**omma (запятая).

- **`apply(context, [argsArray])`**: Аргументы передаются в виде массива.
    - _Как запомнить:_ **A**pply = **A**rray (массив).

**Пример:**

```JavaScript
function showProfile(city, country) {
  console.log(`${this.name} живет в ${city}, ${country}`);
}

const user = { name: 'Elena' };

showProfile.call(user, 'Тбилиси', 'Грузия'); 
showProfile.apply(user, ['Тбилиси', 'Грузия']);
```

**Зачем нужен `apply`, если есть spread (`...`)?**

До появления ES6 и оператора spread, `apply` был единственным способом передать массив данных в функцию, которая принимает аргументы через запятую (например, `Math.max.apply(null, [1, 2, 3])`). Сейчас чаще используют `call` в связке со spread: `func.call(context, ...args)`.

---
#### 2. Метод `bind()`

В отличие от предыдущих, `bind` **не вызывает функцию сразу**. Он возвращает **новую функцию**, у которой контекст привязан «намертво».

- **Синтаксис:** `const boundFunc = func.bind(context, arg1, arg2)`.
- **Каррирование (Partial Application):** `bind` позволяет зафиксировать не только `this`, но и часть аргументов.

**Пример:**

```JavaScript
const user = { name: 'Elena' };

function logMessage(level, message) {
  console.log(`[${level}] ${this.name}: ${message}`);
}

// Привязываем контекст и первый аргумент
const logError = logMessage.bind(user, 'ERROR');

logError('Что-то пошло не так'); // [ERROR] Elena: Что-то пошло не так
```

### Сводная таблица для интервью

|**Метод**|**Вызов**|**Аргументы**|**Что возвращает**|
|---|---|---|---|
|**`call`**|Сразу|Перечисление (`arg1, arg2`)|Результат выполнения функции|
|**`apply`**|Сразу|Массив (`[arg1, arg2]`)|Результат выполнения функции|
|**`bind`**|Потом|Любым способом|**Новую функцию**|

### Важные нюансы для «звездочки» (Senior Level):

1. **Повторный `bind`:** Нельзя перепривязать контекст у функции, которая уже создана через `bind`. Второй и последующие вызовы `.bind()` на ту же функцию просто проигнорируют новый контекст.
2. **`null` или `undefined` в качестве контекста:**
    - В **non-strict mode**: `this` станет глобальным объектом (`window`/`global`).
    - В **strict mode**: `this` останется `null` или `undefined`.
3. **Приоритет:** Вызов через `new` имеет более высокий приоритет, чем `bind`. Если вызвать `new` на функцию, созданную через `bind`, `this` будет указывать на новый объект, а не на тот, что мы привязывали.
