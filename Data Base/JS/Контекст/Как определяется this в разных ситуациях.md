**1. Глобальный контекст и вызов обычной функции** Если функция вызывается сама по себе (не как метод объекта и не через `new`), значение `this` зависит от строгого режима (`use strict`):

- **Без строгого режима:** `this` ссылается на глобальный объект. В браузере это `window`, в Node.js — `global`. Сейчас принято использовать универсальное `globalThis`.
- **В строгом режиме (`'use strict'`):** `this` будет `undefined`.
- _Частый вопрос на собесе: "Что выведет `console.log(this)` просто в скрипте (вне функции)?"_ Ответ: Глобальный объект (даже в строгом режиме). `undefined` он становится только _внутри_ вызванной обычной функции.

**2. Метод объекта** Когда функция вызывается как метод объекта, `this` привязывается к объекту, который стоит **перед точкой** в момент вызова.

```JavaScript
const user = {
  name: 'Elena',
  greet() {
    console.log(this.name);
  }
};
user.greet(); // this === user, выведет 'Elena'
```

_Важный нюанс для собеса:_ Неважно, где функция была создана, важно, как она вызвана. Если мы оторвем метод от объекта и вызовем его отдельно, контекст потеряется (но это мы подробнее разберем в третьем пункте твоего плана).

**3. Использование с `new` (функция-конструктор)** Если функция вызывается с ключевым словом `new`, под капотом происходит магия. `this` привязывается к **совершенно новому пустому объекту**, который создается в памяти. Пошагово это работает так:

1. Создается новый пустой объект `{}`.
2. Ключевое слово `this` начинает ссылаться на этот новый объект.
3. Выполняется тело функции (обычно туда добавляются свойства, например `this.name = ...`).
4. Функция неявно возвращает этот объект `this` (если явно не возвращен другой объект).

```JavaScript
function User(name) {
  this.name = name;
}
const dev = new User('Frontend'); // this внутри User ссылается на новый объект dev
```
