Потеря контекста происходит тогда, когда мы **отрываем метод от объекта** и вызываем его просто как обычную функцию. В этот момент связь с объектом (тот самый "объект перед точкой") исчезает.

Есть две классические ситуации:

**1. Передача метода как колбэка (классика в `setTimeout`)**

```JavaScript
const user = {
  name: 'Elena',
  greet() {
    console.log(`Привет, я ${this.name}`);
  }
};

setTimeout(user.greet, 1000); // Выведет: "Привет, я undefined"
```

_Почему так?_ `setTimeout` принимает саму функцию `greet`. Когда через секунду движок JS вызовет её, он сделает это просто как `greet()`, без привязки к `user`. А в обычной функции без объекта `this` — это `globalThis` или `undefined`.

**2. Присваивание метода переменной**

```JavaScript
const user = {
  name: 'Elena',
  greet() { console.log(this.name); }
};

const looseGreet = user.greet; // Оторвали метод
looseGreet(); // undefined
```

---
### Как решать проблему (4 способа)

На собеседовании от тебя ждут перечисления этих способов от самых современных к "древним".

#### 1. Использование стрелочной функции (Самый частый способ в современном коде)

Так как у стрелки нет своего `this`, она возьмет его из внешнего окружения в момент создания.


```JavaScript
// В колбэке:
setTimeout(() => user.greet(), 1000); // Работает!

// Или сразу объявить метод стрелкой (часто используется в React-классах раньше):
const user = {
  name: 'Elena',
  greet: () => { console.log(this.name); } // ОСТОРОЖНО! Так делать нельзя.
};
```

_Внимание, ловушка!_ Если объявить метод объекта как стрелку прямо в литерале объекта, `this` будет ссылаться на глобальный объект, а не на `user`! Стрелки захватывают контекст из внешней _функции_, а объект не создает свою область видимости.

#### 2. Жесткая привязка через `.bind()`

Метод `bind()` создает новую функцию, которая "намертво" привязана к указанному контексту.

```JavaScript
const user = {
  name: 'Elena',
  greet() { console.log(this.name); }
};

const boundGreet = user.greet.bind(user);
setTimeout(boundGreet, 1000); // Работает!
```

#### 3. Обёртка в анонимную функцию

Мы не передаем метод напрямую, а вызываем его внутри другой функции прямо на объекте.

```JavaScript
setTimeout(function() {
  user.greet(); // Точка перед greet() на месте, контекст сохранен!
}, 1000);
```

#### 4. Сохранение контекста в замыкании (Legacy / Устаревший способ)

Ты вряд ли будешь писать так в 2026 году, но на собеседовании стоит упомянуть, чтобы показать кругозор. Раньше контекст сохраняли в локальную переменную.

```JavaScript
const user = {
  name: 'Elena',
  greet() {
    const self = this; // или const that = this;
    setTimeout(function() {
      console.log(self.name); // Используем сохраненную ссылку
    }, 1000);
  }
};
```
