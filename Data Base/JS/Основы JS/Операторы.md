#### 1. Арифметические операторы

Все стандартно (`+`, `-`, `*`, `/`, `%`, `**`), но помни про:

- **Бинарный плюс (`+`)**: Единственный, кто умеет конкатенировать строки.
    
- **Инкремент/Декремент (`++`, `--`)**: В JS они часто встречаются в циклах, но в React-разработке их стараются избегать из-за мутаций (предпочтительнее `count + 1`).
    

#### 2. Операторы сравнения

- **Строгое (`===`, `!==`)** vs **Нестрогое (`==`, `!=`)**: На собеседовании всегда говори: «Использую только строгое, чтобы избежать неявного приведения типов».
    
- **Сравнение объектов**: Сравниваются **ссылки**, а не содержимое. Два одинаковых по виду объекта `{a:1} === {a:1}` дадут `false`.
    

#### 3. Логические операторы (Short-circuit evaluation)

В JS они возвращают не просто `true/false`, а **значение одного из операндов**.

- **ИЛИ (`||`)**: Возвращает первый _truthy_ (истинный) операнд.
    
- **И (`&&`)**: Возвращает первый _falsy_ (ложный) операнд.
    
    - _Кейс:_ В React `{items.length && <List />}` — если длина 0, на экране отобразится цифра `0`, так как `&&` вернет её как первое ложное значение. Правильнее: `items.length > 0 && ...`.
        
- **НЕ (`!`)**: Приводит к булеву типу и инвертирует. `!!value` — быстрый способ привести любое значение к `boolean`.
    

#### 4. Nullish Coalescing (`??`)

Оператор нулевого слияния. Возвращает правый операнд, только если левый — `null` или `undefined`.

- Важно в UI: если `0` или `""` — это валидные данные, которые нельзя заменять на «дефолт», используй `??` вместо `||`.
    

#### 5. Операторы Spread (`...`) и Rest (`...`)

Выглядят одинаково, работают по-разному в зависимости от контекста:

- **Spread (расширение)**: «Распаковывает» массив или объект. Используется для создания копий (shallow copy).
    
    - `const NewObj = {...oldObj, key: 'value'};`
        
- **Rest (остаток)**: Собирает «оставшиеся» аргументы в массив или свойства в объект.
    
    - `const {name, ...others} = user;`

### 🔥 Что точно спросят (Ключевые моменты)

**1. Унарный плюс (`+`)** Самый быстрый способ привести строку к числу.

- `+'5' // 5 (число)`
    
- `+true // 1`
    
- `+new Date() // timestamp`
    

**2. Приоритет и ассоциативность (Precedence)** Это база, которую часто забывают. Например, у оператора присваивания (`=`) приоритет очень низкий, и он выполняется **справа налево**. А у арифметических — слева направо.

- _Вопрос:_ Что будет в `a = b = 5`?
    
- _Ответ:_ Сначала `b` станет 5, затем `a` станет результатом этого выражения (тоже 5).
    

**3. Оператор «Запятая» (Comma operator)** Позволяет выполнить несколько выражений, разделенных запятой, и возвращает результат **последнего**.

- `let a = (1, 2, 3); // a = 3`
    
- Редко, но встречается в минифицированном коде или сложных `for`-циклах.
    

**4. Оператор `delete`** Удаляет свойство из объекта.

- _Важно:_ Он не удаляет сам объект и не работает с обычными переменными, объявленными через `const/let`. Он возвращает `true`, если удаление успешно.
    

**5. Оператор `void`** Вычисляет выражение и всегда возвращает `undefined`.

- Используется для создания ссылок, которые ничего не делают: `<a href="javascript:void(0)">`.
    
- `void 0` — часто используется как надежный способ получить `undefined`, так как в старых браузерах `undefined` технически можно было перезаписать.
    

---

### Резюме для заметок:

1. `??` — только для `null/undefined`.
    
2. `||` — для любого _falsy_ значения.
    
3. `!!` — быстрый каст в `boolean`.
    
4. `...` (Spread) — создает **поверхностную** копию.
    
5. `+` (унарный) — быстрый каст в `number`.
