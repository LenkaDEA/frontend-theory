В JS есть два вида приведения: **Явное** (Explicit) и **Неявное** (Implicit).
#### 1. Три основных преобразования
**А. В строку (ToString)**
- Происходит при `String(value)` или при бинарном `+`, если один из операндов — строка.
- Объекты превращаются в `"[object Object]"`, если не переопределен `toString`.
- Массивы превращаются в список элементов через запятую: `[1, 2].toString() // "1,2"`.

**Б. В логическое значение (ToBoolean)** Это самое простое. Нужно просто запомнить **6 «ложных» (falsy) значений**:
1. `false`
2. `0` (и `-0`, `0n`)
3. `""` (пустая строка)
4. `null`
5. `undefined`
6. `NaN` 
> Все остальное — `true` (включая пустые массивы `[]` и объекты `{}`).

**В. В число (ToNumber)** Происходит при арифметических операциях (`-`, `*`, `/`, `%`), унарном плюсе `+` и операторах сравнения (`>`, `<`).
- `null` → `0`
- `undefined` → `NaN`
- `true` / `false` → `1` / `0`
- Строки: обрезаются пробелы по краям. Пустая строка → `0`. Ошибка в строке (буквы, пробелы между чистами) → `NaN`.
---
**1. Алгоритм «Двойного равно» ( == vs === )
- `===` (строгое): Сравнивает и тип, и значение. Если типы разные — сразу `false`.
- `==` (нестрогое): Пытается привести типы к одному (обычно к числу) перед сравнением.
    - `null == undefined` // `true` (это исключение в спецификации).
    - `0 == ''` // `true` (оба приводятся к 0).
    - `false == []` // `true` (оба приводятся к 0).

**2. Ловушка бинарного плюса (+)** Оператор `+` — единственный, который перегружен.
- Если есть **хотя бы одна строка** → происходит конкатенация (приведение к строке).
- Во всех остальных случаях (числа, булевы значения, null) → происходит сложение (приведение к числу).
Примеры:
    - `1 + '2' = '12'`
    - `1 + 2 + '3' = '33'`
    - `true + 5 = 6`

**3. Приведение объектов (ToPrimitive)** Когда мы пытаемся сложить объект с числом или строкой, JS вызывает внутренний алгоритм `ToPrimitive`. Он ищет методы в следующем порядке:

1. `Symbol.toPrimitive(hint)` — если определен, используется только он.
2. Если `hint` "string": `toString()` -> `valueOf()`.
3. Если `hint` "number" или "default": `valueOf()` -> `toString()`.

_Нюанс для Senior-позиции:_ Обычные объекты `{}` по умолчанию имеют `valueOf`, который возвращает сам объект (игнорируется), поэтому в итоге всегда срабатывает `toString`.

**4. Классические вопросы-загадки:**

- `[] + []` — `""` (два пустых массива превращаются в пустые строки и складываются).
- `[] + {}` — `"[object Object]"` (массив стал `""`, объект стал `"[object Object]"`).
- `{} + []` — В консоли может выдать `0`, потому что `{}` интерпретируется как пустой блок кода, а `+[]` как унарный плюс к массиву (который дает 0).
---
**Заметка для подготовки:** На интервью часто дают выражение типа `true + [1]`. _Разбор:_ `[1].toString()` это `"1"`. Получаем `true + "1"`. Так как есть строка, `true` тоже станет строкой. Итог: `"true1"`.
